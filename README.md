# Cameyware 部署监控（CameywareBuildMonitor）

服务器上正在做什么，一目了然：上传和载入镜像、启动、健康检查、官网重建，以及 CMS 的部署和 GitHub Actions 的构建，预览站和正式站都有。

这个仓库只有**网页**（前端）。数据来自 cameyware_api 的 `services/build-monitor`（后端，`/ops/v1`），后端读取服务器上一个只看不改的小程序（agent）每 5 秒写下的快照。

## 怎么用

- 预览站：<https://preview.cameyware.com/ops/>（和预览站一样在 Cloudflare Access 后面），用官网的账号登录，网站管理员和超级管理员可以查看。
- 四个页签：**预览站**、**正式站**（正在进行的部署、每个项目的服务是否在线和版本、部署记录）、**CMS 部署**、**GitHub 构建**。
- 有部署在进行时每 3 秒刷新，平时每 15 秒。

## 开发

| 命令            | 做什么                                                                                     |
| --------------- | ------------------------------------------------------------------------------------------ |
| `npm run sync`  | 从官网复制配色、Mantine 主题和全局样式，从 cameyware_api 复制公司的地址（`src/generated`） |
| `npm run dev`   | 本机预览（端口 8813；`NEXT_PUBLIC_API_ROOT` 指向后端）                                     |
| `npm run build` | 静态导出到 `out/`（`/ops/` 下）                                                            |
| `npm run lint`  | 类型检查和格式检查                                                                         |

部署：在 cameyware_api 的 `services/app-lumingmijie` 运行 `npm run deploy:preview`，它会构建这个页面并放到预览站的 `/ops/`。

## 更新记录

### v0.4.0（2026-11-26）：赛博风格的新界面，圆盘进度和总时长（禄命秘解 S80）

- **新界面**：深色是深蓝底加淡淡的网格和青色、品红的霓虹光，浅色是冷白底配同样的强调色；卡片切角，左上角一道霓虹线；正在进行的部署边框会发光呼吸。只改部署监控自己，官网和 CMS 不变。
- **圆盘进度**：正在进行的部署有一个大圆盘，按这个环境平常一次部署多久来填（中间是百分比和已用时间），每次前进都会弹一下；进行中外圈有一段光在转。上传用小圆盘显示进度，进行中的步骤是跳动的光点，完成的步骤会弹出一个勾。系统设置了「减少动态效果」时不播放动画。
- **总时长**：每次部署显示总时长（进行中显示已用时、平常多久、预计还要多久），部署记录里也有。
- **本机构建**：部署脚本上报的本机步骤标「本机」，并写明是谁在哪台电脑（电脑名、系统、CPU 和核数、内存）上部署的；搜索也能按电脑和部署人找。
- 验证：类型检查、格式检查、构建；浅色、深色和手机宽度的截图都看过。

### v0.3.0（2026-11-26）：从 CMS 打开时直接登录

- **从 CMS 打开**：在 CMS 右上角菜单点「部署监控」，这个页面用 CMS 当前的账号直接登录（一次性的登录码，用过就失效），不用再输入密码；部署监控有自己的登录，不影响 CMS 的。没有登录码或登录码失效时照常显示登录框。
- **职位**：同时是网站编辑和网站经理的人（禄命秘解 S79）照样看不了，只有网站管理员和超级管理员能看。
- 验证：类型检查、格式检查、构建；后端的测试。

### v0.2.0（2026-11-26）：网站图标，可以安装成应用

- **网站图标**：公司的标志用绿色，右下角一个心跳线，浅色和深色各一套，和官网、CMS 的图标是一家。
- **快捷访问**：在 Chrome 或 Edge 里打开 <https://preview.cameyware.com/ops/>，点地址栏右边的「安装」图标（或菜单 → 投放、保存和分享 → 安装页面为应用），它就成了桌面和任务栏上的「部署监控」，单独一个窗口打开；手机上用「添加到主屏幕」。CMS 右上角的菜单里也有「部署监控」。
- 验证：类型检查、格式检查、构建；图标在浅色和深色下、16 和 96 像素都看过。

### v0.1.0（2026-11-26）：第一版（禄命秘解 S77）

- **预览站、正式站**：正在进行的部署（每一步的状态和用时，上传显示已传多少、约占多少、速度）；按项目分组的服务（在线、启动中、不健康、已停止，版本，启动了多久）；部署记录（分页、按状态筛选并显示条数、搜索）。
- **CMS 部署**：CMS 自己的发布和重建，每次的状态、用时和日志。
- **GitHub 构建**：四个仓库最近的构建；进行中的显示正在跑的步骤。需要一个只读的 GitHub 令牌（见页面上的说明）。
- **登录**：用官网的账号，只有网站管理员和超级管理员能看；这个页面有自己的登录，不影响官网的登录。
- 验证：类型检查、格式检查、构建；浅色、深色和手机宽度都看过。
